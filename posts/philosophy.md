### 网页哲学：极简、纯粹与长久

在当今充满了重型 JavaScript 框架、成百上千个 npm 依赖包以及动辄数兆字节 bundle 的现代 Web 开发中，我们常常忽略了网页最初的本真。

> "The web was born simple, and simplicity is its greatest strength."

#### 为什么选择单页与原生浏览器搜索？

1. **零延迟与极速加载**：单页架构无需繁重的路由切换，没有页面跳转的停顿感。
2. **完全可搜索性**：当所有文章都在同一页面呈现在 DOM 中时，无需复杂的全文搜索引擎后端，按下 <kbd>Ctrl</kbd> + <kbd>F</kbd>（或移动端的页面查找），浏览器就能在毫秒级内精确定位到任何关键词。
3. **标签与正文隔离**：为了方便快速定位与检索，本博客为标签采用了单字符 `#` 前缀格式（如 `#TagName`）。这样当你在浏览器中搜索 `#RetroWeb` 时，就能快速定位到对应的标签卡片。

#### 纸张阅读与 Web 1.0 的融合

我们采用了极具质感米黄/暖白纸张色调作为浅色主题，结合经典衬线体（Georgia / 宋体）用于长文阅读；而在深色模式下，则切换为暗色终端 CRT 质感。手写克制的 CSS 与 2px 双边框设计，赋予了它独特的复古美学。
